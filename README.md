# Sistema de Gestão Acadêmica (SGA)

Projeto desenvolvido para a disciplina de **Programar em Linguagem Interpretada** do curso de Análise e Desenvolvimento de Sistemas (ADS).

## 📌 Descrição

O **Sistema de Gestão Acadêmica** tem como objetivo gerenciar entidades e operações do ambiente educacional (alunos, professores, cursos, notas e matrículas).

## 🚀 Tecnologias

- JavaScript / HTML / CSS / Node.js (conforme requisitos da disciplina)
